# Плеер

Музыкальный плеер для Android в стиле Material 3 (Material You).

- динамические цвета из обоев или свой цвет акцента
- интерфейс на русском
- добавление треков из памяти телефона
- правка названия, исполнителя и обложки
- фоновое воспроизведение с уведомлением

Сборка: GitHub Actions (вкладка Actions → последняя сборка → Artifacts → player-apk).
